# Тест-кейс: Проверка добавления товара в корзину (SauceDemo)

**ID:** TC-CART-001
**Приоритет:** High
**Компонент:** Корзина (Cart)
**Автоматизирован:** Да (`CartTests.java`)

## Предусловия
1. Открыт браузер Google Chrome.
2. Пользователь находится на странице авторизации: `https://www.saucedemo.com/index.html`.

## Тестовые данные
*   Логин: `standard_user`
*   Пароль: `secret_sauce`

## Шаги выполнения (Steps)
| Шаг | Действие | Ожидаемый результат |
| :--- | :--- | :--- |
| 1 | Ввести логин `standard_user` в поле `Username` | В поле отображается введенный текст |
| 2 | Ввести пароль `secret_sauce` в поле `Password` | Текст скрыт точками (маскировка) |
| 3 | Нажать кнопку `Login` | Происходит переход на страницу товаров (`/inventory.html`) |
| 4 | Запомнить название и цену первого товара в списке | Значения сохранены (например, `Sauce Labs Backpack` и `$29.99`) |
| 5 | Нажать кнопку `Add to cart` у первого товара | Счетчик корзины увеличивается на 1, кнопка меняется на `Remove` |
| 6 | Нажать на иконку корзины в правом верхнем углу | Происходит переход на страницу корзины (`/cart.html`) |
| 7 | Сравнить название товара в корзине с запомненным на шаге 4 | Названия идентичны |
| 8 | Сравнить цену товара в корзине с запомненной на шаге 4 | Цены идентичны |
